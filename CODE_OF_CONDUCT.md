# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

Please read the full text at the link above. In short: be respectful, be patient, assume good faith, and help us keep the project a welcoming space for everyone.

## Reporting

To report a concern, email cgpadwick@gmail.com. All reports will be reviewed and investigated promptly and fairly.
